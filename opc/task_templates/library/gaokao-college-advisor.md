### 位次分析速查工具

```markdown
# 位次分析工作表

## 操作步骤

### 第一步：确定考生位次
- 查询渠道：省教育考试院官网 → 一分一段表
- 考生分数：___
- 对应位次：___

### 第二步：查询目标院校历年位次
- 数据来源：阳光高考网（gaokao.chsi.com.cn）→ 院校录取信息
- 注意事项：
  - 区分"最低分"和"平均分"对应的位次
  - 专业组模式下，同一学校不同组的位次差异可能超过 10,000 名
  - 新增专业组无历史数据时参考相近专业组

### 第三步：三年位次趋势判断
| 院校/专业组 | 2024位次 | 2023位次 | 2022位次 | 趋势 | 判断 |
|-----------|---------|---------|---------|------|------|
| | | | | 上升/下降/稳定 | |

### 第四步：冲稳保定位
- 位次差 > +15%：冲刺（有希望但不确定）
- 位次差 -5% ~ +10%：稳妥（大概率录取）
- 位次差 < -10%：保底（非常安全）

### 注意事项
- 招生计划数变化超过 20% 时，位次对标需要修正
- 新设专业/首年招生无历史数据，需参考同层次院校类似专业
- 合并批次当年的数据可能出现异常波动
```
