## 技术交付物

### 技术方案大纲模板

```markdown
# [项目名称] 技术方案

## 第一章 项目概述
### 1.1 项目背景
- 政策背景（对标国家/省/市政策文件）
- 业务背景（甲方面临的核心问题）
- 建设目标（可量化的目标指标）

### 1.2 建设内容概述
- 总体建设内容一览表
- 与甲方现有系统的关系说明

### 1.3 建设原则
- 统筹规划、集约建设
- 安全可控、自主可靠（信创要求）
- 开放共享、协同联动
- 以人为本、便捷高效

## 第二章 总体设计
### 2.1 总体架构
- 技术架构图（分层：基础设施层/数据层/平台层/应用层/展示层）
- 业务架构图（流程视角）
- 数据架构图（数据流转视角）

### 2.2 技术路线
- 技术选型及理由
- 信创适配方案
- 与现有系统的集成方案

## 第三章 详细设计
### 3.1 [子系统一] 详细设计
- 功能清单
- 业务流程
- 接口设计
- 数据模型
### 3.2 [子系统二] 详细设计
（同上结构）

## 第四章 安全保障方案
### 4.1 安全架构设计
### 4.2 等保三级合规设计
### 4.3 密码应用方案（国密算法）
### 4.4 数据安全与隐私保护

## 第五章 项目实施方案
### 5.1 实施方法论
### 5.2 项目组织与人员配置
### 5.3 实施计划与里程碑
### 5.4 风险管理
### 5.5 培训方案
### 5.6 验收标准

## 第六章 运维保障方案
### 6.1 运维体系
### 6.2 SLA 承诺
### 6.3 应急预案

## 第七章 典型案例
### 7.1 [标杆案例一]
- 项目背景
- 建设内容
- 建设成效（数据说话）
### 7.2 [标杆案例二]
```

### 投标文件检查清单

```markdown
# 投标文件检查清单

## 资质类（废标项，逐条核对）
- [ ] 营业执照（经营范围覆盖招标要求）
- [ ] 相关资质证书（CMMI、ITSS、信息系统集成资质等）
- [ ] 等保测评相关资质（如需乙方自持）
- [ ] 信创适配认证/兼容性报告
- [ ] 近三年财务审计报告
- [ ] 无重大违法记录声明
- [ ] 社保/纳税证明
- [ ] 授权委托书（如非法人签署）
- [ ] 联合体协议（如有联合投标）

## 技术方案类
- [ ] 是否逐条响应招标文件技术要求
- [ ] 架构图是否完整清晰（总体架构/网络拓扑/部署架构）
- [ ] 信创方案是否明确产品型号和兼容性说明
- [ ] 等保/密评设计是否独立成章
- [ ] 实施计划是否有甘特图和里程碑
- [ ] 项目团队是否有人员简历和资质证书
- [ ] 案例是否附有合同/验收报告佐证

## 商务类
- [ ] 报价是否在预算控制价范围内
- [ ] 报价明细是否与技术方案中的清单一致
- [ ] 付款条件是否响应招标要求
- [ ] 质保期是否满足要求
- [ ] 是否有不合理低价风险

## 格式类
- [ ] 页码连续、目录对应
- [ ] 签字盖章完整（骑缝章）
- [ ] 正本/副本份数正确
- [ ] 密封要求符合规定
- [ ] 投标保证金已缴纳
- [ ] 电子版与纸质版一致
```
