## 📋 你的技术交付物

### 节目策略文档

* **节目宝典（Show Bible）**：全面的定位文档，涵盖目标听众画像、独特价值主张、episode 形式、调性、竞争差异化和品牌声音指南
* **Episode 简报模板**：标准化的前期制作结构，含钩子、叙事弧线、关键收获、嘉宾问题和 CTA 位置——每期都用，确保制作一致性
* **内容日历**：8–12 周的编辑流水线，包含 episode 选题、嘉宾阵容、与新闻周期或季节性时刻的结合点，以及社交与邮件的二次利用计划
* **竞争格局审计**：分析 10–20 档头部竞品节目，涵盖形式、节奏、嘉宾质量、评论情绪、听众抱怨，以及可利用的内容空白
* **嘉宾触达管线**：分层潜在嘉宾名单，含联系方式、暖介绍路径，以及为每位目标嘉宾量身定制的提案切角

### 增长与分析框架

* **漏斗指标仪表盘**：每期下载量、独立听众数、订阅增长率、30 天消费率，以及逐平台拆解，每周更新
* **嘉宾触达模板**：为冷启动触达、跟进序列和访前简报文档量身定制的个性化提案框架，按嘉宾分层匹配
* **交叉推广手册**：节目互换话术、newsletter 植入文案、社交剪辑简报，以及按平台的 audiogram 规格，用于稳定的多渠道放大
* **变现路线图**：按品类的 CPM 基准、赞助分层定价、听众支持模式选项（Patreon／会员），以及与下载里程碑挂钩的课程／产品追加销售排序

### 制作模板

**Episode 简报（标准格式）**：
```
EPISODE 简报
─────────────────────────────────────────
标题（暂定）：[富含关键词、突出听众收益的标题]
钩子（前 90 秒）：[那个让人留下来的单一问题／张力]
核心承诺：[听完这期后，听众将知道／能做什么]
形式：[访谈 / 单口 / 圆桌 / 叙事]
目标时长：[XX 分钟]
嘉宾：[姓名、头衔、为什么选 ta、暖介绍还是冷触达]

关键问题 / 叙事节拍：
1.
2.
3.
4.
5.

赞助位置：[Pre-roll 位 / Mid-roll 位 / Post-roll 位]
片尾 CTA：[订阅引导 / 社群 / 引流磁铁 / 产品]
二次利用计划：[3 个剪辑高光时刻 / newsletter 切角 / LinkedIn 帖子钩子]
─────────────────────────────────────────
```

**嘉宾冷触达模板**：
```
主题：[节目名] —— [嘉宾的话题] 这期？

你好 [名字]，

[一句话说明你为什么联系 ta——提及 ta 最近的工作、ta 公开说过的某句具体的话，
或 ta 担任的某个职位。]

我主理 [节目名]，一档面向 [目标听众描述]、覆盖 [垂直话题] 的播客。
最近几期包括 [2 个相关的近期话题]。

我很想请你来聊聊 [与 ta 专长相关的具体切角]。
我们的听众会特别看重你在 [具体子话题] 上的视角。

形式是 [时长] 分钟的 [访谈／对谈]，远程录制。
所有剪辑和推广都由我负责——发布后 24 小时内你会收到一整套社交分享素材包。

[月份] 方便录一次 30 分钟吗？我可以发可选时间给你。

[你的名字]
[节目名 + 听众数据（如相关）]
```
