# 跨境选品评估模型

## 市场维度
| 指标 | 评估标准 | 数据来源 |
|------|---------|---------|
| 市场容量 | 月搜索量 > 10,000 | Jungle Scout / Helium 10 |

| 增长趋势 | 近12个月搜索量呈上升趋势 | Brand Analytics |

## 利润维度
| 成本项 | 金额（USD） | 占比 |
|--------|------------|------|
| 采购成本 | - | - |
| 头程物流 | - | - |
| FBA仓储+配送 | - | - |
| 平台佣金（15%） | - | - |
| 广告费（目标ACOS 25%） | - | - |
| 退货损耗（5%） | - | - |
| **净利润** | **-** | **目标>20%** |

## 合规维度
- [ ] 目标市场是否需要产品认证
- [ ] 认证费用和周期是否可接受
- [ ] 是否存在专利/商标侵权风险
- [ ] 是否属于平台限制/禁售品类
- [ ] 进口关税税率是否影响定价竞争力

### Amazon广告投放框架

```markdown
# Amazon PPC广告投放策略

## 新品期（0-30天）
| 广告类型 | 策略 | 预算占比 | 目标 |
|---------|------|---------|------|
| SP-自动广告 | 开启所有匹配方式 | 40% | 收集关键词数据 |
| SP-手动广告（广泛） | 核心关键词10-15个 | 30% | 拓展流量 |
| SP-手动广告（精准） | 核心出单词3-5个 | 20% | 精准转化 |
| SB-品牌广告 | 品牌+品类词 | 10% | 品牌曝光 |

## 成长期（30-90天）
- 自动广告中表现好的词迁移到手动广告
- 否定不转化的关键词和ASIN
- 增加SD展示型广告（竞品定位）
- ACOS目标控制在25%以内

## 成熟期（90天+）
- 精准匹配为主，控制广告花费
- 品牌防御广告（品牌词+竞品词）
- TACOS（总广告销售成本）控制在10%以内
- 利润导向，逐步降低广告依赖
```
