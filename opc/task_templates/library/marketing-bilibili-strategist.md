### 中长视频脚本结构模板

```markdown
# B站视频脚本模板

## 基本信息
- 时长目标：8-15分钟
- 内容类型：深度解析/知识科普
- 目标完播率：> 30%（中长视频标准）

## 脚本结构

### 开头（0:00-0:30）：黄金30秒
- 抛出核心问题或悬念："你有没有想过，为什么XXX？"
- 价值预告："看完这期视频，你会明白XXX的底层逻辑"
- 避免冗长自我介绍，直奔主题

### 第一部分（0:30-3:00）：背景铺垫
- 交代必要背景信息
- 用具体案例或数据引入
- 插入弹幕互动点："到这里的扣1"

### 第二部分（3:00-8:00）：核心内容
- 分2-3个小论点展开
- 每个论点配具体案例/数据/对比
- 每2-3分钟设置一个节奏变化点（梗、类比、可视化）
- 信息密度保持适中，不堆砌也不注水

### 第三部分（8:00-12:00）：深度延伸
- 给出独到见解或预测
- 呼应开头的悬念/问题
- 设置"高能"片段，引发弹幕高潮

### 结尾（12:00-13:00）：收束与互动
- 一句话总结核心观点
- 引导互动："你怎么看？评论区聊聊"
- 预告下期内容（如果是系列）
- "一键三连"引导要自然，不要太刻意

## 制作要点
- 画面辅助：PPT/图解/实拍混合，避免纯口播
- BGM选择：匹配内容节奏，避免版权风险
- 字幕必加：关键术语和数据用字幕强调
- 封面：主题文字 + 视觉冲击 + 不误导
```

### UP主商业化合作方案模板

```markdown
# B站品牌合作方案

## UP主画像
- 粉丝量级：XX万
- 核心分区：科技/生活/游戏/知识
- 粉丝画像：年龄、城市、兴趣偏好
- 平均播放量：XX万
- 互动率：XX%（点赞+投币+收藏/播放）

## 合作形式选择
| 类型 | 适用场景 | 价格区间 | 用户接受度 |
|------|---------|---------|-----------|
| 定制视频 | 品牌深度种草 | 最高 | 取决于内容质量 |
| 口播植入 | 品牌曝光 | 中等 | 较高（如果自然） |
| 片尾贴片 | 低预算曝光 | 最低 | 一般 |
| 直播推荐 | 即时转化 | 中等 | 看直播调性 |

## 内容植入策略
1. 找到品牌与UP主内容的自然结合点
2. 用UP主自己的语言风格介绍产品
3. 保留UP主的真实评价权（允许说缺点）
4. 在简介区标注"本期含商业合作"

## 效果评估
- 播放量 vs UP主近期均值
- 弹幕中品牌关键词出现频率
- 评论区对商业内容的正面/负面比
- 搜索指数变化
```
