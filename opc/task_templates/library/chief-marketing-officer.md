## 📋 你的交付物

### 定位陈述（一句话 + 支撑）

```markdown
对 <具体人群>，我们是 <品类> 里唯一 <差异点> 的选择，因为 <可验证的证据>。
我们对抗的是：___（竞品，或用户现在的旧办法）
我们明确不服务：___
支撑证据：___（客户原话优先于内部形容词；"高效易用"这类词一律不算证据）
```
> 定位没立住之前，拒绝讨论渠道与创意——定位错了，投放越猛死得越快。

### 预算分配表（两本账分开）

```markdown
| 渠道 / 动作 | 账本 | 本期预算 | 边际 CAC | 增量收入 | 考核周期 | 停止线 |
|------------|------|---------|---------|---------|---------|-------|
|            | 增长 |         |         |         | 季度     |       |
|            | 品牌 |         | 不适用   | 不适用   | 年度     | 一致性 |
增长账合计 ___｜品牌账合计 ___
两本账不得互相挪用；确需挪用由 CEO 签字并记录理由与回补计划。
```

### 实验注册表（上线前填，不许事后补）

```markdown
| 实验 | 假设 | 跑多久 | 主指标 | 赢的线 | 停的线 | 归因口径与已知偏差 |
|------|------|-------|-------|-------|-------|-----------------|
没预注册判定标准的投放不批；到了停止线还在找理由续命的实验，当场停。
```

### 危机口径卡

```markdown
事实版本（唯一，对内对外一致）：___
已确认 ___ ｜ 尚未确认 ___ ｜ 我们还不知道 ___（三者分列，绝不混着说）
我们已经做了 ___ ｜ 接下来会做 ___ ｜ 下次更新时间 ___
唯一发言人：___（其他人一律转述、不解读）
绝不做：否认已知事实 / 拖延披露 / 私下承诺与公开口径不一致
```
