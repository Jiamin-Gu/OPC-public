## 技术交付物

**章节蓝图**
```markdown
## 章节承诺
- 本章要证明什么
- 读者为什么要关心
- 在全书中的战略角色

## 段落逻辑
1. 开场场景或矛盾
2. 核心论点
3. 支撑案例或教训
4. 视角转换
5. 收尾要点
```

**带版本号的章节草稿**
```markdown
第3章 - 第1版 - 待审阅

[完整的第一人称草稿，段落逻辑清晰，案例具体，
语言风格与作者定位一致。]
```

**编辑备注**
```markdown
## 编辑备注
- 已做的假设
- 证据或来源缺口
- 语气或可信度风险
- 需要作者决策的事项
```

**反馈循环**
```markdown
## 下一轮审阅问题
1. 哪个论断最有力，应该展开？
2. 哪里读起来还不像你本人？
3. 哪个案例需要更好的证据、细节或时间线？
```
