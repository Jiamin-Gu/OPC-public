# 轻记 CLI 记账工具（code/ 使用说明）

**版本依据**：依据 `docs/PRD.md` v1.1 与 `docs/技术方案.md` v1.2，冲突以文档为准。技术方案最新即 v1.2，此前误写 v1.3 已改回。唯一例外：`--date` 空串/纯空白按非法日期报错，技术方案 4.3 未显式写空值，来自测试审查意见与本实现显式校验，已实测记入 `code/verify.log` 4-E/4-F，列入待确认第 5 条。本工具本机运行、只支持人民币、数据存本地 JSON，不做账号/联网/第三方包；实现 `add`/`summary`/`stats`，`export` 不做。

## 运行环境

- Python 3.9+，仅标准库，无需 pip install；实测 3.12.15，3.9~3.11 未实测。
- 在 `code/` 下执行 `python cli.py <子命令> [参数]`；根目录 `python code/cli.py ...` 也可。输出含中文，终端建议 UTF-8。
- `cli.py` 管入口/参数/异常退出码；`ledger.py` 管金额、校验、模型、JSON 读写、汇总统计。技术方案原拆 `ledger/` 包，本实现合并为单文件，对外函数名与技术方案 4.2 一致，测试可按接口导入。详见完整版。

## 命令用法

- 只支持 CNY，不做多币种/汇率。金额以“分”整数存储计算，代码无浮点类型/运算；元→分正则解析，分→元整除/取余，显示两位小数。`35.80`→`amount_cents=3580`。
- 金额合法：`35`、`35.8`、`35.80`、`0.05`；整数 1~12 位、小数最多 2 位，上限 `999999999999.99` 元。非法：空、`0`、`0.00`、负数、`+`/`-`、`¥`、逗号、空格、科学计数法、小数超 2 位。
- 日期 `YYYY-MM-DD` 须补零且真实存在；月份 `YYYY-MM`。分类固定 8 类：餐饮、交通、购物、居住、娱乐、医疗、教育、其他；收支共用，不支持自定义。
- `--data PATH` 是每个子命令的可选参数，写在子命令之后，默认 `./data/ledger.json`。

### add（记一笔）

- `python cli.py add --type {income,expense} --amount 元 --category 分类 [--date YYYY-MM-DD] [--note 文本] [--data PATH]`。
- `--type`/`--amount`/`--category` 必填；`--note` 省略存空字符串（非 `null`）。先全量校验、后写入，失败不改数据文件。
- `--date` 完全不传才用本机当天；传空串或纯空白按非法日期报错、退出码 2、不写入，不静默改成今天。口径详见待确认第 5 条。

### summary（按月汇总）

- `python cli.py summary --month YYYY-MM [--data PATH]`。
- 按 `YYYY-MM` 汇总收入、支出、结余（收入−支出，可为负）与笔数；不统计其他月份。
- 只读；文件不存在或该月无记录按 0 条，退出码 0，不创建文件。

### stats（按分类统计）

- `python cli.py stats --month YYYY-MM [--type {expense,income}] [--data PATH]`；`--type` 省略为 `expense`。
- 只统计该月该类型；按金额降序，并列按固定 8 类顺序；只列有记录分类；占比 1 位小数（四舍五入，不补差），合计行固定 `100.0%`。
- 无记录时只输出一行提示，退出码 0，不输出表格。

### export（导出 CSV）：本期不做

按 CEO 指示与 `docs/PRD.md` v1.1 第 8 章、`docs/技术方案.md` ADR-6，本期不提供 `export` 子命令、不实现 CSV 生成，编号保留不复用。需要备份直接复制 `data/ledger.json`。将来恢复导出前需重新确认列定义、编码与转义口径。

### 退出码

- `0` 成功（含空数据/无该月记录）；`2` 参数或校验错误；`3` 文件/IO 错误；`1` 未预期错误兜底。
- 错误一律写 stderr、单行、以“错误：”开头；校验失败时数据文件不变。

## 数据存储位置

- 默认 `./data/ledger.json`，相对当前工作目录；`--data PATH` 可覆盖。换目录执行会看到不同账本。
- 只有 `add` 创建文件（目录不存在自动创建）；新建时 stderr 额外一行 `（已新建数据文件：<绝对路径>）`，非 stdout 契约。`summary`/`stats` 不创建。
- 写入：读入→追加→同目录临时文件→`os.replace` 原子替换，中断不留半截 JSON。
- 文件 UTF-8 无 BOM、2 空格缩进，`version:1`；金额只有整数分 `amount_cents`；`id` 从 1 严格自增；损坏或 `version` 非 1 读取报错退出 3，绝不改写原文件。
- 单用户单进程，不加写锁。备份 `cp data/ledger.json data/ledger.json.bak`；测试用 `--data` 指向临时文件，避免污染真实账本。

## 示例输出

- 完整示例见完整版与 `code/verify.log`。关键：`summary` 出收入/支出/结余，`stats` 按金额降序；`35.8` 与 `35.80` 等价，落盘均 `amount_cents=3580`。
- 金额精度卡口：`0.10`+`0.20` 显示交通 `2 笔 0.30 元`，不出现浮点误差。
- 空数据：`summary` 三行全 0，`stats` 输出“该月没有支出记录”，退出 0，不创建文件。
- 非法输入：金额 `1.005`、分类 `旅行`、日期 `2026-02-30`/空串、月份 `2026-13`、`--type transfer` 等均 stderr、退出 2、不写入。完整实测详见完整版。
